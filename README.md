# JogoSol — Sol Errante

Protótipo de jogo web (um único arquivo: `index.html`). Abra no navegador.

Um sol incandescente vaga pela arena. Clique sobre ele, **arraste** na direção desejada e solte
para aplicar um empurrão. Como o sol tem muita inércia, um empurrão só desvia um pouco a rota.

Controles laterais: aleatoriedade do movimento, quantidade de obstáculos, massa/inércia e velocidade de cruzeiro.
